Описание
Telegram бот — игровой автомат с очками и мультиплеером. Игроки могут крутить слоты, получать ежедневный бонус, смотреть баланс и вызывать друг друга на игру с реальными ставками.

Функции

/start — регистрация пользователя, стартовый баланс 100 очков
Кнопки меню:
🎰 КРУТИТЬ — сыграть на 10 очков
💰 Баланс — посмотреть баланс очков
🎁 Бонус — получить ежедневный бонус (1 раз в сутки)
🤝 Multiplayer — информация о мультиплеере
/dep @username amount — передать очки другому игроку
/challenge @username ставка — вызвать пользователя на мультиплеерную игру в слоты
Вызванный игрок получает личное сообщение с кнопками "Принять" и "Отклонить"
Игра по очереди, ставки списываются, выигрыши распределяются
При отсутствии личного чата с ботом — уведомление вызывающему, что нужно начать чат с ботом
